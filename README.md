## 🚀 Como Executar

Para compilar e executar os códigos deste repositório, certifique-se de ter um compilador C (como o GCC) instalado em sua máquina.

```bash
# Navegue até a pasta da aula desejada
cd Aula_02

# Compile o arquivo .c
gcc nome_do_arquivo.c -o programa

# Execute o programa gerado
./programa
```
